# shooting_block

> 一个基于 Pygame 的休闲益智游戏，融合了 **2048 数字合并**、**物理弹射** 和 **三消消除** 三种玩法。

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Pygame](https://img.shields.io/badge/Pygame-2.x-green.svg)

## 🎮 游戏简介

从屏幕左下角**点击发射方块**，方块会在场景中自由弹跳并落入右侧网格区域。相同等级的方块相邻时会**自动合并升级**（2→4→8→16→32→64），当三个或以上满级方块连成一线时触发**三消消除**，获得大量分数。

### ✨ 核心玩法

| 机制 | 说明 |
| :--- | :--- |
|  **弹射发射** | 鼠标点击任意位置，从左下角向目标方向发射方块 |
| 🔀 **物理弹跳** | 方块在自由落体阶段会碰壁反弹，带有加速度效果 |
| 🔗 **合并升级** | 两个相同等级的相邻方块自动合并为更高等级（最高 64） |
| 💥 **三消消除** | 三个及以上满级（64）方块横向或纵向相连时触发消除动画 |
| ⬅️➡️ **手动整理** | 按 A/D 键将所有方块向左/向右靠拢，方便合并 |
| 📊 **计分系统** | 合并和三消都会获得分数，三消得分 = 数量³ × 等级 |

## 🕹️ 操作方式

| 操作 | 按键/动作 |
| :--- | :--- |
| 发射方块 | **鼠标左键点击**屏幕任意位置 |
| 方块左移靠拢 | **A** 键 |
| 方块右移靠拢 | **D** 键 |
| 退出游戏 | 关闭窗口 |

## 🚀 快速开始

### 环境要求

- Python 3.8+
- pygame 2.x

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/你的用户名/BlockMerge.git
cd BlockMerge

# 2. 安装依赖
pip install pygame

# 3. 运行游戏
python main.py

```

## 🧠 技术要点

- **状态机驱动**：每个方块有 5 种状态（`FREE` 自由落体 → `MOVE` 微调归位 → `STAY` 静止 → `FALL` 下落填充 → `TRIP` 三消动画），通过状态机管理行为切换
- **网格系统**：右侧区域划分为 11×22 的网格（每格 64×64 像素），方块落定后吸附到网格坐标
- **碰撞检测**：基于 `pygame.Rect.colliderect()` 实现方块间的碰撞判定
- **重力模拟**：自由落体阶段使用加速度模型（`acc = [0, 0.0002]`），碰壁时速度反转实现弹性反弹
- **合并锁机制**：通过 `locked` 标志防止同一方块在一帧内被重复合并
- **帧率控制**：锁定 120 FPS，使用 `delta_time` 保证不同性能设备下体验一致
